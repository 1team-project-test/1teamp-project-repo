	사용자 table
1. 사용자 고유id : CHAR(06) (PK)
2. 로그인 e-mail : VARCHAR(30) UNIQUE
3. 비밀번호 : VARCHAR(60)
4. 가입일시 : DATETIME
5. 연령 : INT
 

	검색기록 TABLE
1. 기록로그 : INT (PK)
2. 전화번호 : VARCHR(15)
3. 사용자 고유 ID : CAHR(06) (FK)
4. 스팸여부 : CHAR(1)
5. 검색 날짜와 시간 : DATETIME


	스팸등록 TABLE
1. 전화번호 : VARCHAR(15) (PK)
2. 스팸유형 : CHAR (3)
3. 제보횟수 : INT 
4. 댓글 : VARCHAR(50)
